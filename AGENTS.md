# PoTATo — Pokémon Champions Teambuilder

## Goal
Build a browser-based Pokémon Champions planning tool with format-accurate data for Regulation M-A (Apr 8 – Jun 17 2026). Lazy-load per-format data: index first (Pokémon list), moves/learnsets/items on demand.

## Stack
- **Language**: Vanilla JavaScript (ES modules)
- **Serve**: `python3 -m http.server`
- **Data**: Pre-merged static JSON files per format, generated by `prep/prep_data.py`
- **No frameworks, no bundlers, no build step**

## Running

```bash
# Fetch/merge data (requires network on first run, caches to .cache/)
npm run prep

# Download Champions menu sprites from Bulbagarden Archives
python3 scripts/download-sprites.py

# Build sprite → species mapping
python3 scripts/build-sprite-map.py

# Start dev server
npm start                # → http://localhost:8787
```

## Data Pipeline

### Sources
1. **Base data**: `https://play.pokemonshowdown.com/data/pokedex.json` (SV-era stats/moves)
2. **Mod overrides**: `https://raw.githubusercontent.com/smogon/pokemon-showdown/master/data/mods/champions/` — `moves.ts`, `items.ts`, `abilities.ts`, `formats-data.ts`, `learnsets.ts` (Champions-specific balance changes)
3. **Legality lists**: Hardcoded in `prep/prep_data.py` (Regulation M-A species/moves/items from MetaVGC lists)

### Logic
1. Fetch base JSON files from Showdown servers
2. Fetch mod TS files from GitHub, parse them (regex-extract the override objects)
3. Merge: base values → apply mod overrides on top
4. Filter by Regulation M-A whitelists (species, moves, items)
5. Include battle-only forms (megas, regionals, Rotom appliances) — added from pokedex `otherFormes`
6. Output 4 JSON files per format into `data/format-{id}/`
7. Mega learnsets inherit from their `baseSpecies`
8. Floette (base) is included in learnsets since Floette-Mega's `battleOnly` is "Floette-Eternal" but the base Floette is the actual pre-evo

### Critical Discovery
`isNonstandard` **cannot** be used for M-A legality filtering:
- Floette-Mega has `isNonstandard: "Future"` but IS legal in M-A
- Floette-Eternal has `isNonstandard: "Past"` but shows 14.6% usage
- The mod's `formats-data.ts` has a `tier` field as source of truth for Champions legality
- M-A legality = Champions mod non-Illegal species ∩ corrected M-A whitelist ∪ overrides
- Species whitelist is still needed because Champions includes species banned in M-A format (legends, mythicals) — 46 extra forms filtered out

### Sprite Source
Menu sprites are downloaded from [Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Champions_menu_sprites) using their MediaWiki API. The download script computes the file URL from the MD5 hash of the filename (MediaWiki's standard `{hash[0]}/{hash[0:2]}/{filename}` path convention). Sprites are saved to `sprites/champions/` as PNGs, then `sprite-map.json` maps each species ID to its filename using dex number + form suffix matching.

## Frontend Architecture

### SortBar Component (`lib/sort-bar.js`)
Reusable pill-based sort UI used by all search widgets.

```javascript
this.sortBar = new SortBar({
  container: sortBarContainer,
  options: [
    { key: 'alpha', label: 'A-Z' },                                      // default sort toggle
    { key: 'type', label: 'Type', onClick: showTypeDropdown },           // onClick overrides toggle
    { key: 'bp', label: 'BP', onClick: showStatPopup },                // onClick for popup
    { key: 'acc', label: 'ACC', onClick: showStatPopup },
  ],
  activeKey: this.sortBy,
  activeDirection: this.sortAsc ? 'asc' : 'desc',
  onChange: (key, direction) => { /* update sort state */ },
});
```

- `_sortButtons` Map exposes buttons: `this.sortBar._sortButtons.get(key)` for popup positioning
- `setActive(key, direction)` — programmatically set active pill + direction
- `destroy()` — removes DOM
- Default direction: numeric keys (`hp`, `atk`, `def`, `spa`, `spd`, `spe`, `bp`, `acc`, `pri`) sort descending; others ascending
- When `onClick` is provided, the default sort toggle behavior is replaced — call `this.onChange` manually if needed

### Stat Popup Pattern (Pokémon / Moves)
Each stat pill opens a popup with:
- Direction buttons (Ascending/Descending) — highlights active direction only when that stat is the active sort key
- Min/Max range inputs (0–N clamped) with live bounds filtering
- Apply button (closes popup)
- Enter key on inputs closes popup
- Click outside closes popup

Bounds stored per-key in `this.statBounds` object. Active bounds highlighted with `.bounds-active` CSS class (gold text on stat pill, gold text on the input).

### Filter Dropdown Pattern (Type / Classification / Effect)
Pill opens a dropdown. Clicking a popup-item adds a filter chip. Dropdown closes on outside click, scroll, resize.

Move "Move Classification" dropdown has two groups: Classifications (Biting, Pulse, Sound-Based, etc.) and Effects (Weather Setting, Priority, etc.).

### Reset Button Pattern
Added to filter row (right of search input) in moves/abilities/widgets. CSS: `ps-mega-toggle ps-reset-btn`. Always styled as "active" (bg-active, text-primary, border-strong, no gold border). Resets all widget state.

### CSS Class Prefixes
- `.ps-*` — Pokemon search widget
- `.ms-*` — Move search widget
- `.as-*` — Ability search widget
- `.is-*` — Item search widget
- `.tb-*` — Team builder

### Widget Sort Bar CSS Alignment
Sort bar pills use `nth-child(n)` to set widths aligning to list columns. Example (moves):
```css
.ms-sort-bar .sort-bar-btn:nth-child(1) { width: 9rem; }   /* A-Z → name */
.ms-sort-bar .sort-bar-btn:nth-child(2) { width: 4.5rem; }  /* Type → type col */
.ms-sort-bar .sort-bar-btn:nth-child(3) { width: 2.5rem; }  /* BP */
.ms-sort-bar .sort-bar-btn:nth-child(4) { width: 2.5rem; }  /* ACC */
```

`.sort-bar { flex-wrap: nowrap; }` prevents pills from wrapping.

### Widget Lifecycle Pattern
Widgets created lazily on first tab activation. `app-init.js` holds widget references on `widgets` object and destroys/recreates on format change.

### Three PokemonSearchWidget Instances
1. Main grid (`pokemonWidget`) — Pokédex tab, created eagerly
2. Move detail "Learned By" list — within SearchDetailView
3. Ability detail "Pokémon with..." list — within SearchDetailView

### Two MoveSearchWidget Instances
1. Moves subtab — full move list, lazy-initialized
2. Pokemon detail moves list — filtered by species learnset, managed inside SearchDetailView
