# PoTATo — Pokémon Champions Teambuilder

## Goal
Build a browser-based Pokémon Champions planning tool with format-accurate data for Regulation M-A (Apr 8 – Jun 17 2026). Lazy-load per-format data: index first (Pokémon list), moves/learnsets/items on demand.

## Stack
- **Language**: Vanilla JS with TypeScript (tsc only, no bundler)
- **Serve**: `python3 -m http.server`
- **Data**: Pre-merged static JSON files per format, generated by `prep/prep_data.py`
- **No frameworks, no bundlers**

## Data Pipeline

### Sources
1. **Base data**: `https://play.pokemonshowdown.com/data/pokedex.json` (SV-era stats/moves)
2. **Mod overrides**: `https://raw.githubusercontent.com/smogon/pokemon-showdown/master/data/mods/champions/` — `moves.ts`, `items.ts`, `abilities.ts`, `formats-data.ts`, `learnsets.ts` (Champions-specific balance changes)
3. **Legality lists**: Hardcoded in `prep/prep_data.py` (Regulation M-A species/moves/items from MetaVGC lists)

### Logic
1. Fetch base JSON files from Showdown servers
2. Fetch mod TS files from GitHub, parse them (regex-extract the override objects)
3. Merge: base values → apply mod overrides on top
4. Filter by Regulation M-A whitelists (species, moves, items)
5. Include battle-only forms (megas, regionals, Rotom appliances) — added from pokedex `otherFormes`
6. Output 4 JSON files per format into `data/format-{id}/`
7. Mega learnsets inherit from their `baseSpecies`
8. Floette (base) is included in learnsets since Floette-Mega's `battleOnly` is "Floette-Eternal" but the base Floette is the actual pre-evo

### Critical Discovery
`isNonstandard` **cannot** be used for M-A legality filtering:
- Floette-Mega has `isNonstandard: "Future"` but IS legal in M-A
- Floette-Eternal has `isNonstandard: "Past"` but shows 14.6% usage
- The mod's `formats-data.ts` has a `tier` field as source of truth for Champions legality
- M-A legality = Champions mod non-Illegal species ∩ corrected M-A whitelist ∪ overrides
- Species whitelist is still needed because Champions includes species banned in M-A format (legends, mythicals) — 46 extra forms filtered out

### Species Legality Pipeline (prep_data.py)
1. **Champions legality**: mod `formats-data.ts` entries with `tier != "Illegal"`
2. **M-A whitelist**: 213 non-Mega + 60 Mega IDs (fixed version of MetaVGC-derived list)
3. **Overrides**: `meowsticf` (gender form not in mod formats-data)
4. **Mega detection**: use pokedex `forme` field not string match (fixes Meganium misclassification)
5. **Validation**: warn on whitelist species not in mod data, AND mod species not in whitelist

### Sprite Source
Menu sprites are downloaded from [Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Champions_menu_sprites) using their MediaWiki API. The download script computes the file URL from the MD5 hash of the filename (MediaWiki's standard `{hash[0]}/{hash[0:2]}/{filename}` path convention). Sprites are saved to `sprites/champions/` as PNGs, then `sprite-map.json` maps each species ID to its filename using dex number + form suffix matching.

### Champions Mod Changes Verified
- Trop Kick: 70 → **85 BP**
- Moonblast: added 10% SpA drop chance
- Various other buffs/nerfs in Champions-specific gameplay

### Ability Data Pipeline
1. Fetch abilities from Showdown base data (`pokedex.json`), apply Champions mod overrides
2. Filter to M-A legal species only
3. Fetch descriptions from Game8 page (`https://game8.co/games/Pokemon-Champions/archives/590403`) via regex `<tr>\s*<td[^>]*class="center"[^>]*>\s*(?:<a[^>]*>)?\s*([A-Za-z][A-Za-z\s\'\-]+?)\s*(?:</a>)?\s*</td>\s*<td[^>]*>([^<]+)</td>` — falls back to Showdown `desc` on failure
4. Attach `pokemon` array (species IDs that can have the ability) and `effectCategories` array (broad mechanic tags like `weather`, `stats`, `priority`, etc.)
5. `num` field removed (Showdown internal ID, not used in frontend)
6. Battle Bond excluded (not on Game8 list)
7. Categories defined in `get_ability_categories()` in `prep_data.py` using explicit ID-based assignment

### Item Data Pipeline (categorize_items.py)
1. Categories match Game8's official item types: **Defense, Recovery, Power Boost, Other, Stat Boost, Mega Stone**
2. Type-resist berries (Chilan, Haban, Babiri, etc.) → **Defense**; Oran/Sitrus berries → **Recovery**; Leftovers/Black Sludge → **Recovery**
3. `ITEM_CATEGORIES` in `item-search-widget.ts` defines the category order for filter buttons
4. `category` field added to each item in `items.json`

## Running

```bash
# Fetch/merge data (requires network on first run, caches to .cache/)
npm run prep

# Download Champions menu sprites from Bulbagarden Archives
python3 scripts/download-sprites.py

# Build sprite → species mapping
python3 scripts/build-sprite-map.py

# Compile TypeScript
npm run build

# Start dev server
npm start                # → http://localhost:8787
```

## TypeScript Conventions
- `moduleResolution: "bundler"` with `module: "ES2022"`
- All imports use `.js` extension (for ES module compatibility)
- `import type` for type-only imports (elided at compile time)
- `outDir: "dist/"` — `index.html` loads `dist/app.js` as module
- Strict mode enabled: `strict`, `noUnusedLocals`, `noUnusedParameters`

## Frontend Architecture
- **`app.ts`**: Format selector dropdown → loads index → renders card grid (with sprites). On card click: lazy-fetches learnsets + moves, switches to Search Detail tab with stats, abilities, move list, and team slots. Also manages tab/subtab system, move/ability detail views, breadcrumbs in search detail, and widget lifecycle.
- **`lib/data-loader.ts`**: `setFormat()`, `loadIndex()`, `loadLearnsets()`, `loadMoves()`, `loadMovesWithLearnsets()`, `loadAbilities()`, `loadItems()` — each returns a promise, cached after first fetch. Layer 1 = fetch JSON; Layer 2 = render from cache
- **`lib/types.ts`**: `Species`, `Move`, `Item`, `Ability`, `FilterFlag`, `FormatData`, `DataCache` interfaces + `FormatId` type (`'m-a' | 'm-b'`)
- **`lib/move-search-widget.ts`**: `MoveSearchWidget` class — builds own DOM for search input, filter popup, sort controls, result grid. Emits `onMoveClick`. Includes `RANGE_CATEGORIES`, `MOVE_CLASSIFICATIONS`, `EFFECT_CATEGORIES`, `TYPES`, `TYPE_COLORS` exports.
- **`lib/pokemon-search-widget.ts`**: `PokemonSearchWidget` class — builds own DOM with `.ps-*` prefixed selectors (avoids ID conflicts with multiple instances). Supports card/list view, sort by dex/alpha/stats, mega toggle, filter popup (type/ability/move/classification/effect/ability_category), `setLearnedByFilter()`, `onPokemonClick`. Accepts `species`/`spriteMap`/`learnedByFilter` in constructor for one-shot initialization.
- **`lib/ability-search-widget.ts`**: `AbilitySearchWidget` class — builds own DOM for search input, filter popup with effect categories, sort controls, result list. Emits `onAbilityClick`. Exports `ABILITY_EFFECT_CATEGORIES` label map.
- **`lib/team-store.ts`**: `TeamStore` class — `getTeams()`, `saveTeam()`, `deleteTeam()` backed by localStorage.
- **Sprites**: 320 `Menu_CP_{dex}_{form}.png` files served from `sprites/champions/`, mapped by `sprite-map.json`

## Key Patterns
- Three `PokemonSearchWidget` instances can exist: main grid (`pokemonWidget`), move-detail learned-by (`moveDetailPokemonWidget`), and ability-detail pokemon list (`abilityDetailPokemonWidget`) — `.ps-*` classes prevent CSS ID conflicts
- Two `MoveSearchWidget` instances exist: one for the Moves subtab (`movesWidget`), one for per-species detail (`detailMovesWidget`)
- Click-highlight uses direct DOM class toggling (`.selected`), not re-renders
- Move descriptions come only from Game8 (`shortDesc`); `desc` stripped in prep pipeline
- `target` field renamed to `range` in both data and frontend; values remapped to natural labels
- Only classification flags kept in move data; mechanical flags and `protect` stripped
- `switchToDetail()` guards against redundant tab-switching when already on the detail tab
- `PokemonSearchWidget` accepts `learnedByFilter` in constructor to avoid a double render (all species → filtered)
- Breadcrumbs at the top of the Search Detail view, rendered into `#breadcrumb-bar` (outside the content area), with click-navigation and trail management (truncation, index shift)
- **`ItemSearchWidget`**: `ITEM_CATEGORIES` exports Game8 item types — Defense, Mega Stone, Other, Power Boost, Recovery, Stat Boost. Type-resist berries classified as Defense; Oran/Sitrus berries as Recovery. Category buttons filter items; sorting alphabetical only.
